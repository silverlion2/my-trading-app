# Options Radar

A React and Vite trading dashboard that visualizes options-market positioning, gamma exposure, max pain, call walls, put walls, and ticker-level risk signals.
[Live site](https://my-trading-app-xi.vercel.app)

## What This Project Covers

- Options-market dashboarding
- Ticker-level GEX and max-pain analysis
- Trader education and risk visualization

## Tech Stack

- React
- Vite
- JavaScript
- Vercel
